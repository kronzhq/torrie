Built natively for macOS with Zed's GPU-accelerated UI framework and a fast Rust BitTorrent engine.

Control it from anywhere

Open the built-in web remote in any browser, or connect another app with the settings shown here.

  1. In Settings, open Network and turn on Remote control, and Allow other devices for anything that isn't this Mac.
  2. Restart Torrie.
  3. Open http://<your Mac's IP>:9091 in any browser and sign in with the password shown in Settings.

Make it yours with plugins

A plugin is just a folder with a plugin.json. Add commands to the Plugins menu, tabs to the Inspector, options to Settings, or run a script when a download finishes.

  1. Hooks run on torrent-added, torrent-done and torrent-done-seeding.
  2. Plugin processes talk JSON-RPC 2.0 over stdin and stdout, in any language.
  3. Share a .torrieplugin package with a one-click torrie://install link.

Read the plugin docs →

{
  "id": "media-organizer",
  "name": "Media Organizer",
  "version": "1.0.0",
  "description": "Renames finished movies for Plex",
  "hooks": {
    "torrent-done": "on-done.sh"
  }
}
