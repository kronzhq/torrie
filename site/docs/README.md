# Getting started

Download [Torrie.dmg](https://dl.kronz.xyz/torrie/Torrie.dmg), drag Torrie to Applications and launch it once. It then opens `.torrent` files and `magnet:` links. Torrie needs macOS 12 or later.

| | |
|---|---|
| Settings file | `~/Library/Application Support/Torrie/settings.json`, readable by you only |
| Plugins folder | `~/Library/Application Support/Torrie/plugins/` |
| Add a torrent | Drag in a `.torrent`, click a `magnet:` link, or paste one with `Cmd+U` |
| Inspector | `Cmd+I`: overview, files, peers and trackers |

- [Remote control](remote-control.md): the web remote, Torrie's API and the Transmission protocol.
- [Plugins](plugins.md): hooks, plugin processes, packages and recipes.
